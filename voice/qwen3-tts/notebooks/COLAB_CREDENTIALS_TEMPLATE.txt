Tsuki epoch-0 Colab TTS credentials template
================================================

This is a safe template. Do not put real credentials in this file, commit it,
or share it publicly.

The notebook is self-contained for its code and public model assets, but
VPS-connected mode still requires the following runtime secrets.

1) Colab TTS API key
--------------------

Colab file path:
  /content/tsuki_colab_tts_api_key

File contents:
  PASTE_THE_SAME_VALUE_AS_THE_VPS_TTS_API_KEY_HERE

Use one line only. The value must match the VPS setting named:
  TSUKI_QWEN_TTS_API_KEY

The notebook can prompt for this value instead of using a file.

2) Cloudflare tunnel credentials (recommended)
-----------------------------------------------

Colab file path:
  /content/tsuki_colab_tunnel_credentials.json

File contents must be the complete credentials JSON for the named tunnel,
with these fields:
  AccountTag
  TunnelSecret
  TunnelID
  Endpoint

Do not paste real JSON into this template.

Alternative token file:
  /content/tsuki_cloudflare_tunnel_token

Its contents are one Cloudflare tunnel token line. The notebook uses the
credentials JSON first and falls back to the token file.

Current tunnel/hostname configuration
--------------------------------------

Tunnel name:
  tsuki-colab-qwen-custom

Public hostname:
  colab-tts.tsukihime.dpdns.org

The hostname must resolve through Cloudflare to the active Colab tunnel.

Colab run requirements
----------------------

1. Select a T4 GPU runtime.
2. Open hf_epoch0_colab_service.ipynb.
3. Provide the API key and one Cloudflare credential method above.
4. Run all cells.

No Hugging Face token or model upload is needed for the current public model
repository and pinned revision.

Connection flow
---------------

VPS -> https://colab-tts.tsukihime.dpdns.org -> Cloudflare tunnel
    -> Colab FastAPI service at http://127.0.0.1:8100

Security notes
--------------

- Never commit or upload a file containing real secrets.
- Prefer Colab runtime secrets/getpass or short-lived runtime files.
- Do not print credentials in logs or notebook output.
- If a credential is exposed, revoke/rotate it immediately.
- A mismatched API key causes the VPS-to-Colab request to return HTTP 401.
