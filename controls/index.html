Conversation awareness

DISCORD ONLY

Direct requests and short same-speaker follow-ups can receive replies. Background conversation is observed briefly in process memory and does not call the reply model or speech system.

Text reply mode “Only @mentions” still requires an actual @mention or reply to Tsuki. Select “All messages” under Server settings to consider contextual chat turns. Manual /tfocus and selected channels always take priority.

Checking optional classifier configuration…

The classifier uses the existing private Groq key pool and runs only for ambiguous eligible turns. A model ID does not prove API-key or model availability; errors abstain. Clear the ID and use wake-only or context-aware modes to disable it.
